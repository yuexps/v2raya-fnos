# v2rayA for fnOS

A deeply integrated v2rayA application for fnOS.

## Features

- **Native Unix Socket Integration**: Uses Unix Domain Socket for backend communication, ensuring ZERO TCP port occupation for the management interface.
- **Full Architecture Support**: Compatible with both **x86_64** and **ARM64** platforms.
- **Dual Core Support**: Seamlessly switch between **v2ray-core** and **xray-core**.

## Version Info

- **v2rayA Version**: 2.2.7.5
- **v2ray-core Version**: 5.48.0
- **xray-core Version**: 26.3.27
- **Supported Architectures**: x86_64, ARM64

## Access

After installation, simply click the **v2rayA** icon on the fnOS desktop to access the management interface.

## Core Selection

### During Installation
The installation wizard will guide you to select your preferred proxy core:
- **v2ray-core**: The classic V2Ray implementation, known for its stability.
- **xray-core**: Enhanced performance and support for the latest protocols like REALITY.

### Post-Installation Change
You can change the core at any time:
1. Open the v2rayA management interface.
2. Go to the "Application Settings" or the specific core selection wizard.
3. Select your desired core and save.
4. **Restart the application** to apply the changes.
